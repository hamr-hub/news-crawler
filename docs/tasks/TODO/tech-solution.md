# 新闻爬虫系统技术方案

## 1. 背景与目标

**项目背景**：
用户需要构建一个新闻聚合爬虫系统，解决新闻来源分散、无法及时获取最新内容、重复内容过多、爬虫错误需人工修复等问题。

**目标**：
- 自动通过主流搜索引擎（Google/Baidu/Yandex）发现新闻网站
- 对新闻网站自动归类（国家、新闻类型）
- 循环爬取最新新闻内容并去重
- AI 自动修复爬取错误
- GitHub 发布后自动处理 Issue

## 2. 范围

### 做
- 通过 Google/Baidu/Yandex 等搜索引擎搜索新闻网站
- 对新闻网站自动归类（国家、新闻类型）
- 循环爬取各新闻网站最新内容
- 相同内容新闻汇总去重
- 爬取出错时 AI 校对并修复
- 发布到 GitHub 并自动处理 Issue

### 不做
- 爬取需要登录的付费新闻
- 存储原始网页内容（只存结构化数据）

## 3. 架构设计

### 模块划分

### 核心流程

1. **网站发现阶段**：通过搜索引擎查询新闻网站关键词，解析搜索结果获取新闻网站列表
2. **分类标注阶段**：对发现的网站进行国家和新闻类型分类
3. **爬取阶段**：使用 Playwright 爬取网站动态内容，提取新闻数据
4. **去重阶段**：基于内容相似度对新闻去重
5. **修复阶段**：检测爬取错误，使用 AI 修复爬虫代码
6. **Issue 处理阶段**：监听 GitHub Issue，自动识别并修复

## 4. 关键技术

### Scrapy + Playwright
- 使用 Scrapy 作为爬虫框架
- 使用 Playwright 处理 JavaScript 渲染的动态内容
- 支持反爬策略检测与绕过

### AI 修复
- 使用 OpenAI API 进行错误分析
- 自动生成修复代码
- 验证修复有效性

### 数据存储
- JSON 格式存储新闻数据
- 按日期组织文件结构

## 5. 验收标准

| ID | 描述 | 验证方法 |
|----|------|----------|
| AC1 | 通过搜索引擎发现主流新闻网站 | 运行搜索脚本，输出至少 50 个新闻网站 |
| AC2 | 新闻网站按国家和类型归类 | 输出包含 country 和 category 字段的站点列表 |
| AC3 | 循环爬取新闻内容 | 定期执行爬虫，输出 JSON 格式新闻数据 |
| AC4 | 相同内容新闻去重汇总 | 同一新闻多来源只保留一条 |
| AC5 | AI 自动修复爬取错误 | 模拟爬取错误，AI 识别并修复爬虫代码 |
| AC6 | GitHub Issue 自动修复 | 创建测试 Issue，系统自动识别并修复 |
| AC7 | 数据以 JSON 格式保存 | 检查输出目录存在 JSON 文件 |

## 6. 监控指标

- **爬取成功率**：爬取成功比例
- **错误率**：爬取错误比例
- **去重率**：重复新闻比例
